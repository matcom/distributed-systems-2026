Project submission

Section titled “Project submission”

Your project counts as submitted once your team opens a GitHub issue containing all of the following:

  • Project topic
  • Full name and class group of each student, listed together
  • Link to the project solution

Every team member must contribute to the project and be ready to explain and defend the entire solution individually.
